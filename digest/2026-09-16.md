### Anthropic Engineering: Scaling Managed Agents: Decoupling the brain from the hands
Anthropic 推出了 **Managed Agents**：一个在 Claude Platform 上代用户运行长周期 agent 的托管服务，核心设计思想是“为尚未被设想的程序而设计”。他们借鉴操作系统用 process 和 file 抽象跑赢硬件迭代的思路，把 agent 虚拟化为三个可独立替换的接口：**session**（只追加的事件日志）、**harness**（调用模型并路由工具的循环）和 sandbox（执行环境）。文章还坦诚分享了踩坑经历：最初把三者塞进单个容器，结果服务器变成了不能丢的“宠物”而非“牲畜”，容器一挂 session 就丢，且因容器内有用户数据，工程师几乎无法 debug。最终方案是把“大脑”（Claude 和 harness）与“双手”（sandbox 和工具）以及 session 解耦，各自成为最少假设的接口，也让客户 VPC 连接成为可能。[详情](https://www.anthropic.com/engineering/managed-agents)

### Claude Blog: Claude Code now supports artifacts
Claude Code 新增 **Artifacts** 功能，能把工作过程直接变成可分享、会自动更新的可视化网页。一个 session 的工作可以输出为 **PR walkthrough、系统说明页、可筛选的 dashboard、发布检查清单**等形态，且基于 session 的完整上下文（代码库、connector、对话本身）构建，无需自己接线数据源。页面是“活的”：每次发布都是同一链接下的新版本，带版本历史可随时回滚。内部测试中最常见的场景是排障：工程师站会前发起 incident 调查，Claude Code 自动发布带时间线、嫌疑 commit 和错误率图表的 artifact，站会开始前已经随着调查进展更新了两版，团队所有人看的是同一视图。默认**私有于组织内**，仅认证成员可见，管理员可设置保留策略并通过合规 API 进行组织级审计。[详情](https://claude.com/blog/artifacts-in-claude-code)
