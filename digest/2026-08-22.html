Anthropic Engineering: Scaling Managed Agents: Decoupling the brain from the hands

Anthropic 工程团队详解了 Managed Agents 的架构设计哲学：harness 中编码的假设会随模型进步而过时，例如为 Sonnet 4.5 的"context anxiety"设计的 context reset 在 Opus 4.5 上已成了死代码。因此他们借鉴操作系统"为尚未写出的程序设计抽象"的思路，把 agent 虚拟化为三个可独立替换的接口：session(只追加的事件日志)、harness(调用 Claude 并路由工具的循环)和 sandbox(执行环境)。文章还分享了"不要养宠物"的教训：最初所有组件塞进单容器，服务器成了不可丢失的 pet，容器挂掉 session 就丢了，且因容器内有用户数据，工程师甚至无法进 shell 调试。最终方案是把"大脑"(Claude 和 harness)与"双手"(sandbox 和工具)以及 session 解耦，各自成为对彼此假设极少的接口。详情
