### Claude Blog: Claude in Chrome 正式全面上线
Anthropic 宣布 **Claude in Chrome** 正式(GA)面向所有付费 Claude 计划开放，最大变化是 Claude 现在可以在浏览器中**自主执行操作**，而不再需要每一步都获得用户批准。这解决了长期痛点：很多日常工具(内部仪表盘、遗留系统、供应商门户)没有 API 或 MCP 连接，Claude in Chrome 让 Claude 直接使用你已有的登录态查看页面、读写文本、点击链接、翻页和填表。安全方面，每一次自主操作前都有一个**安全分类器**进行验证，确保操作安全且与你的原始请求匹配，不匹配则拦截。针对 prompt injection(网页、邮件中隐藏恶意指令诱导 agent)的防线也有三层升级：Claude 通过不断增长的攻击库训练识别能力(来源包括内部自动化攻击者、外部红队和真实监控)；probes 在 Claude 行动前扫描网页内容，发现可疑攻击时提醒 Claude 保持怀疑并向用户确认；操作验证机制与 Claude Code 的 auto mode 一致，用户也可在设置中关闭改为手动审批。自 2025 年 11 月首次公布浏览器防御以来，Claude 对这类攻击的抵抗力已大幅提升。[详情](https://claude.com/blog/claude-in-chrome-generally-available)
