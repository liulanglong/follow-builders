### Claude Blog: Building intelligent apps for Apple platforms with Claude in the Foundation Models framework
Anthropic 发布了一个全新的 **Swift package**，让 Apple 开发者可以通过 Apple 的 Foundation Models framework 调用 Claude。核心思路是分层协作：设备端模型处理快速本地任务(如摘要、抽取)，最少三行代码即可通过 guided generation 返回带类型的 Swift 值；当请求需要**多步推理、代码生成**或联网搜索、数据分析时，再无缝交给 Claude，并把 Claude 的流式响应直接回灌到同一个 SwiftUI 视图。由于 Apple 框架通过 Generable 注解返回类型化输出，开发者传给 Claude API 的将是干净的结构化输入而非原始用户文本。官方举了具体场景：日记 app 在设备端生成每日提示，再让 Claude 跨数月条目找线索；学习 app 在设备端定义术语，学生追问「这和我们学过的其他内容有什么关系」时交给 Claude。支持将在明天上线，覆盖 **iOS 27、iPadOS 27、macOS 27、visionOS 27 和 watchOS 27**，用 Anthropic API key 登录即可使用，package 自动处理流式传输、工具调用和结构化响应。[详情](https://claude.com/blog/claude-for-foundation-models)
