### Claude Blog: Claude Code now supports artifacts

Claude Code 现在支持将工作进度捕获为 **artifact**，将代码会话转化为可实时更新、可分享的网页。这些 artifact 可以是 PR 走查、系统解释器、数据仪表板或发布检查清单。它基于会话的完整上下文（包括代码库、连接器和对话本身）自动生成，无需额外搭建基础设施。当 agent 更新 artifact 时，页面会实时刷新，团队成员打开的是同一个链接，看到的始终是最新版本，这大大减少了沟通状态更新的时间。所有 artifact 默认对作者私有，管理员可以通过组织级开关和基于角色的权限来管理访问。[详情](https://claude.com/blog/artifacts-in-claude-code)
