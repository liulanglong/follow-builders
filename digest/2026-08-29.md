### Claude Blog: Claude Code now supports artifacts
Claude Code 现在可以把工作进度捕获为 **artifact**：把会话产出变成可分享的实时可视化网页，包括 PR 演练、系统说明、仪表盘和发布清单，并随会话进行自动更新。关键设计是它基于会话的**完整上下文**构建：一个事故页面可以同时汇集代码库里失败的测试和对应函数、监控工具的错误曲线、以及刚跑完的根因分析，不需要额外接线数据源。页面在同一链接上原地刷新，带版本历史，队友看到的就是同一视图，省去了"给我们讲讲 agent 发现了什么"的沟通成本。内部测试中最常见的场景是调试：工程师站会前发起事故调查，Claude Code 发布带时间线、嫌疑 commit 和错误率图表的 artifact，并在调查推进中多次重新发布。所有 artifact 默认私有，仅限组织内认证成员查看，管理员可通过组织级开关、角色范围和合规 API 管理。[详情](https://claude.com/blog/artifacts-in-claude-code)
