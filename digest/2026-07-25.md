### Claude Blog: Claude Code now supports artifacts

Claude Code 现在可以将工作进度捕获为 **artifact**，把 agent 的工作转化为可实时更新的、可分享的可视化页面，包括 PR walkthrough、系统架构说明、数据 dashboard 和发布检查清单等。一个 Claude Code 会话可以从调查一个 incident 到重构一个服务再到分析数月数据，而 artifact 会把整个过程变成一个任何人都可以打开和探索的网页。关键在于，artifact 基于你当前会话的完整上下文构建，包括代码库、连接器和对话本身。一个 incident 页面可以同时汇集失败测试、相关函数代码、来自监控工具的错误率图表，以及会话中的根因分析。当 Claude Code 更新 artifact 时，打开的页面会实时刷新，队友可以立刻看到最新版本，每次发布都是同一链接下的新版本，支持版本回溯。内部测试中最常见的场景是 **debugging**：工程师在 standup 前启动 incident 调查，Claude Code 分析日志后发布一个包含时间线、可疑 commit 和错误率图表的 artifact，随着调查推进自动更新。所有 artifact 默认对作者私有，确认后可分享给组织内已认证成员，管理员可通过 org 级开关和角色权限进行管理。[详情](https://claude.com/blog/artifacts-in-claude-code)
