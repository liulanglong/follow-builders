Aaron Levie (Box CEO)

Levie 的核心判断是：整个互联网还没有为「人人都有个人 agent 替自己跑任务」的未来做好准备。他指出的不是单一产品缺口，而是一整层的空白——当每个人的 agent 都在网络里自主执行任务时，基础设施层会涌现出无穷的新问题与新机会，用户交互方式要重设计，新商业模式也会随之出现。换句话说，agent 时代的互联网协议、身份验证和商业结算机制，今天基本都不存在，这是创业者和平台方都该提前布局的方向。详情

Zara Zhang (Builder，Harvard '17)

她提出一个反直觉的担忧：当下最大的危机之一是人类注意力持续时间的不断缩短，而 agent 的普及会让这件事变得更糟。表面上看，agent 帮我们省下了执行任务的时间，但当她观察到 agent 时代信息流和工作方式的变化后，结论是这些工具可能进一步挤压深度思考的空间，让人更难长时间专注于一件复杂的事。这是对「agent = 效率红利」这一主流叙事的一剂清醒剂。详情
