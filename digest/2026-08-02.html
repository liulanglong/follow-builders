Claude Blog: Claude Code now supports artifacts

Claude Code 现在支持将工作进度捕获为 artifact，将代码会话转化为可实时更新、可分享的网页。这些 artifact 可以是 PR 走查、系统解释器、数据仪表板或发布检查清单。它基于会话的完整上下文（包括代码库、连接器和对话本身）自动生成，无需额外搭建基础设施。当 agent 更新 artifact 时，页面会实时刷新，团队成员打开的是同一个链接，看到的始终是最新版本，这大大减少了沟通状态更新的时间。所有 artifact 默认对作者私有，管理员可以通过组织级开关和基于角色的权限来管理访问。详情

Unsupervised Learning · Ep 92: xAI Co-Founder Unpacks the Future of Model Development

核心收获：AI 领域的下一个重大突破将来自 个人 AI，而 agent 的能力边界远不止于编程，它将重塑整个计算领域。

Igor Babushkin 曾在 DeepMind 领导 AlphaCode 等项目，也是 OpenAI 推理研究的早期成员和 xAI 的联合创始人。他深刻指出，去年 11 月和 12 月是一个转折点，coding agents 突然变得异常强大，以至于所有人都无法忽视它们。他将这种感受比作现代版的《魔法师的学徒》：我们被这些强大工具的能力所吸引，但它们最终可能会失控。他强调："所有计算领域都将成为 agent 的猎物"，因为 agent 能够深刻理解你的生活和工作，并据此采取行动。

关于模型在编程之外的进展，Babushkin 认为 科学发现 是下一个明确的方向，尤其是在数学领域，通过使用 Lean 等形式化验证工具，可以提供清晰的奖励信号来帮助模型改进。但他也指出，在进入更广泛的领域时，数据 将成为一个巨大的瓶颈。详情
