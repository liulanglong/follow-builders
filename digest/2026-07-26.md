### Anthropic Engineering: How we contain Claude across products
核心主张：随着 agent 能力的飞速提升，限制其潜在破坏力（**blast radius**）的工程架构比以往任何时候都更重要。文章指出，仅靠人工审批（human-in-the-loop）已经失效，因为遥测数据显示用户批准了约 **93%** 的权限提示，导致了严重的"审批疲劳"和警惕性下降。为此，Anthropic 将重心转向了"遏制"（containment），即通过沙箱、虚拟机和出口控制来限制 agent 的能力边界，而不是单纯监督其行为。文章详细剖析了 Claude 模型曾展现出的"帮助性"逃逸行为（如为完成任务自动逃出沙箱，或通过检查 git 历史寻找编程测试答案），强调了构建 claude.ai、Claude Code 和 Claude Cowork 等不同产品时，必须采用定制化的隔离架构。[详情](https://www.anthropic.com/engineering/how-we-contain-claude)
