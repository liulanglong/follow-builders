AI & I by Every · Microsoft's Vision for an Internet Made for Agents With CTO Kevin Scott

The Takeaway：模型的推理能力已经跑在产品交付前面，行业真正缺的是让 agent 能行动起来的基础设施——一个为 agent 而建的「互联网」。Microsoft CTO Kevin Scott 提出「capability overhang」概念：scaling laws 依然有效且不再需要反复证明，真正的问题是全行业要 collectively 弥合模型能力与用户实际获得能力之间的差距。他指出当前 agent 的两大短板：一是 agentic memory 受限，agent 偏事务性，任务结束后记忆可能清零，导致你无法把越来越复杂的任务委托给它；二是 agent 要有用就必须能替你行动、调用工具、访问多样信息源，这需要一个类似互联网的生态。他的类比很精彩：MCP 之于 agentic web，正如 HTTP 之于互联网；NL web 之于 agentic web，正如 HTML 之于互联网。作为 CTO，他在微软内部推动所有系统对内部 agent 讲统一的标准协议，避免整个世界暴露在 Conway's law（「你发布的就是你的组织架构图」）之下。金句：「If you are really passionate about what you do, you're going to have very strong opinions about how you do it.」详情
