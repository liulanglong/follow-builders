Swyx (Latent Space 主播、smol.ai 创始人)

核心观点：human I/O 太贵，与其一问一答，不如让 agent 批量提问。他受 Matt Pocock 和 Thariq 的启发做了一个 /align-me 改造版，允许模型一次性抛出一批问题而不是逐轮询问，直觉上和 spec decoding 同理：往前多看 2 到 10 步来提速。他反馈这在设计探索场景里效果出奇地好，并感叹 Matt Pocock、Thariq、Philipp Schmid 三位前沿技能实践者同时参与这个话题的讨论是件美事。详情

Josh Woodward (Google Labs / AI Studio 副总裁)

官宣 Gemini 3.7 Flash：更快、价格便宜 50%，而且从做到上线只用了大约 3 周时间。近 500 个赞的反馈，也是 Google 本轮模型迭代速度的一个直接信号。详情

Boris Cherny (Anthropic Claude Code 团队)

他做了一个相当超前的实验：让 Claude 接管自家应用的日常维护。具体做法是建了一个名为 proj-claude-maintains-apps 的 Slack 频道，由 Claude Tag 在 iOS、Android、Desktop、web、CLI 和 Agent SDK 上跑一堆每日例程：crash fuzzer 在模拟器里乱点找崩溃并定位修复、dup unifier 扫描相似但略有分歧的抽象并提 PR 统一、dead-code remover 删除静态不可达代码、abstraction police 修补漏抽象。结果惊人：几周内这些例程提了 388 个 PR，经 Claude Code Review 加人工审核后合并了
